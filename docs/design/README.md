# 設計文書について

このディレクトリは、開発時の設計工程（6 フェーズと付録）の記録を公開したものです。設計判断記録（`設計判断_V4-D**`）は追記のみで運用しています。公開にあたって次の置き換えをしたほかは、本文は記録時点のままです。置き換えをした設計判断記録には、末尾に「公開時の注記」として置き換えた行を追記しています。

## 公開にあたって置き換えたもの

- 個人の環境を示すパス・名前・セッション名・作業時刻は、一般的な記述に置き換えるか削りました。
- リンク先を公開していないリンクは、リンクを外して「（非公開）」と添えました。フォルダ再編で移動しただけのリンクは、現在のパスへ書き換えました。
- 非公開の文書や作業の呼び名は、次の語にそろえました。

| 元の記述 | 置き換えた語 |
|---|---|
| 作業メモのファイル名 | 作業メモ |
| PoC の報告書・設計仕様・完了報告のファイル名 | PoC 報告・PoC 設計仕様・PoC 完了報告 |
| PoC 内のファイルパスと行番号 | PoC のリポジトリ名（`crewai_beads_renkei` など） |
| PoC の基準タグ | PoC 基準版 |
| 論点を詰めるための質疑の呼び名 | 質疑 |
| 並行して進めた別の作業 | 並行作業 |
| 設計工程の手順書のファイル名 | 設計工程の手順書 |

## 公開していない参照先

記録の中には、このリポジトリに含めていない文書への参照が残っています。一覧はルートの [README.md](../../README.md) の「12. 公開版について」にあります。`outcome/design/` は、フォルダ再編の前の `docs/design/` の呼び名です。

記録に書かれた値（既定モデル・ポートなど）は設計当時のものです。現在の値はコードと各 `config.json` が正です。
